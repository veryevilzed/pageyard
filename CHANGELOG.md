# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Раздел текущей версии `npm run release` берёт в описание релиза на GitHub.

## [0.1.8] — 2026-10-31

### Добавлено
- Разворот: «По две страницы» и «По две при уменьшении» (пары появляются, когда две страницы
  помещаются по ширине); пары с 1-й страницы (1–2, 3–4) или со 2-й (1, 2–3, как в книге)
- Двойной клик по найденной линии / ячейке создаёт поле во всю её ширину от начала линии,
  в том числе из «Просмотра» (переключает в «Заполнение»); с ⇧ — точно в месте клика
- Перевод запоминается: повторный перевод того же текста (после «Убрать перевод», клика по
  карточке или выключения) берётся из кеша без запроса; в сервис уходят только новые блоки

### Изменено
- Окно открывается на всю высоту экрана, страница — по ширине

### Исправлено
- Окно снова сужается (скрытая панель перевода держала ширину); минимальная ширина 560 pt,
  кнопки строки инструментов и панели перевода прячутся, когда места мало

## [0.1.5] — 2026-10-30

### Перевод страниц (Claude / OpenAI)
- Кнопка 文A (⌘⇧T) открывает панель перевода; сама по себе ничего не переводит
- Переключатель «Перевод» в панели: выкл — виден оригинал, панель остаётся открытой;
  вкл при выделенном тексте — переводится только он
- «Перевести выделенное» (и правым кликом), ⌥+рамка — область, «Перевести страницу» — целиком
- Переведённая страница притемняется, перевод лежит белыми карточками на месте оригинала;
  клик по карточке или «Убрать перевод» возвращает оригинал
- Перевод не обрезается: шрифт уменьшается до 5 pt, дальше карточка вытягивается вниз;
  при наведении — полный перевод и оригинал
- Пока идёт перевод, текст подсвечен пульсирующей рамкой с меткой «Перевожу…»;
  несколько кусков можно отправлять подряд
- «В документ» переносит перевод в файл вместо оригинала
- Языки «с» и «на» в панели; ошибки показываются в панели, без модальных окон
- Настройки (⌘,): Claude или OpenAI, ключи в связке ключей macOS, выбор модели (для OpenAI —
  из списка, доступного ключу), проверка, пошаговая инструкция, где взять ключ
- Разбивка страницы на блоки: абзацы, колонки делятся по пустым полосам между ними

### Объекты и экспорт
- ⌘C / ⌘X / ⌘V / ⌘D для добавленных объектов; картинка или текст из буфера вставляются объектом
- Файл → Экспорт → «PDF без аннотаций»; опция «Без аннотаций» в экспорте картинок

### Исправления
- Текст, подписи и отметки чёткие при любом зуме (рисуются слоем поверх страницы, не растром PDFKit)
- Поле ввода больше не крупнее итогового текста при зуме
- Клик по настоящему полю формы всегда попадает в поле; двойной клик по найденной линии / ячейке
  в «Выборе» начинает ввод
- Заметка маркера видна на странице; правка текста полностью закрывает старый текст;
  фокус при открытии окна — на странице

## [0.1.0] — 2026-10-30

Первая публичная сборка.

### Возможности
- Режимы «Просмотр / Заполнение / Редактирование» с отдельной строкой инструментов
- Заполнение PDF без полей: поиск линий, ячеек и квадратиков, прилипание текста и отметок
- Текст кликом или областью с переносом строк, опция «Стирать под текстом»
- Крестики и галочки, подписи (рисование, фото/скан с прозрачным фоном, буфер, iPhone/iPad)
- Правка существующего текста тем же шрифтом с удалением исходных символов из файла (MuPDF)
- Маркер с заметками, сохраняется настоящими PDF-аннотациями и скрывается одной кнопкой
- Страницы: группы при вставке файлов, перетаскивание, поворот, удаление, пустые листы и листы-макеты
- Импорт PDF, картинок, Word/Pages, Excel/Numbers и сканов с iPhone/iPad
- Экспорт страниц в PNG/JPEG, 72–600 DPI

### Сборка
- Universal (Apple Silicon и Intel), macOS 13+, MuPDF собирается из исходников статически
- Подписанные и нотаризованные сборки: `npm run release`
